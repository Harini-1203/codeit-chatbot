# PetLink
A platform to help users post, sell, and adopt pets, connecting pet lovers and helping stray animals find loving homes.

# About the Project
PetLink is a web platform designed to promote responsible pet adoption and sales. It allows users to:
* List pets for adoption or sale.
* Search and browse available pets.
* Adopt or purchase pets from verified users.
The project aims to help stray animals find loving homes and create a community of responsible pet owners.

# Tech Stack
* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: JSON Web Tokens (JWT)
* CSS Framework: Tailwind CSS

# Installation
Prerequisites: 
Node.js (v16 or later)
MongoDB
Steps:
1. npm install
2. Create a .env file in the backend directory.
      1. MONGO_URI=<your_mongodb_connection_string>  
      JWT_SECRET=<your_jwt_secret_key>  
      PORT=5000
3. cd backend
4. npm run start
5. cd ../frondend
6. npm start
